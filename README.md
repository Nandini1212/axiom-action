# Nandini1212/axiom-action

Public wrapper around Axiom's GitHub Action. This repository carries no Axiom source code --
only this action.yml (identical to the real one, pointed at this repository's own public
releases) and the plain-bash bootstrap scripts it calls to download and verify the actual
Axiom CLI distribution at run time.

## Installing

No token, secret, or access to the private `Nandini1212/axiom` repository is needed -- a
release-asset download from this repository needs no authentication, since it is public.

**Java** (JUnit-style XML, auto-discovered):

```yaml
steps:
  - uses: actions/checkout@v4
  - uses: actions/setup-java@v4
    with:
      distribution: temurin
      java-version: '21'
  - name: Run tests
    run: ./gradlew test
  - name: Investigate any failures
    if: always()
    uses: Nandini1212/axiom-action@v1.15.1
    with:
      axiom-version: 'v1.15.1'
```

**Python** (pytest, via `pytest-json-report`):

```yaml
steps:
  - uses: actions/checkout@v4
  - name: Install pytest-json-report
    run: pip install pytest-json-report
  - name: Run tests
    run: pytest --json-report --json-report-file=.report.json
  - name: Investigate any failures
    if: always()
    uses: Nandini1212/axiom-action@v1.15.1
    with:
      axiom-version: 'v1.15.1'
      report-file: .report.json
```

The explicit `axiom-version` input above is required, not optional: this action.yml's own
default lags one release behind the tag itself (the same real, documented quirk the upstream
Axiom project's own README explains), so omitting it can request a CLI version that was never
mirrored into this repository's own releases.
